# /piv:plan - 创建实施计划

根据 PIV Loop 的 PLAN 阶段，创建详细的实施计划。

## 输入

用户需求描述或任务说明

## 执行步骤

### 1. 需求分析
- 理解核心需求和边界条件
- 识别涉及的技术栈和子项目
- 确定是否有现有代码可以复用

### 2. 范围界定
- 明确本次开发的范围
- 识别跨子项目的依赖关系
- 标记非本次开发范围的内容

### 3. 任务拆分

#### 任务分解模板
```markdown
## 实施计划: [任务名称]

### 阶段一: [阶段名称]
1. [具体任务]
   - **文件**: `路径`
   - **描述**: 做什么
   - **验收标准**: 如何验证完成

### 阶段二: [阶段名称]
...

### 风险与依赖
- **风险**: [描述] → 缓解措施
- **外部依赖**: [依赖项]
```

### 4. 技术决策点
列出需要用户确认的技术选择

## 输出格式

将计划保存到 `.agents/plans/{日期}-{任务名}.md`

```markdown
# 实施计划: [任务名]

## 概述
[简述任务目标和预期结果]

## 范围

### 包含
- [范围列表]

### 不包含
- [排除范围]

## 任务列表

### 阶段一: [名称]
| 任务 | 文件 | 描述 | 验收标准 |
|------|------|------|---------|
| 1.1 | `path/file` | 描述 | 标准 |

### 阶段二: [名称]
...

## 技术决策
- [决策点]: 待确认

## 风险
- [风险描述]: [缓解措施]
```
