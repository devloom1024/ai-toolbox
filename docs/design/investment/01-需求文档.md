```

│                    AI 投资顾问（顾问型）                           │
```

## 三、账号管理设计

### 3.1 账号类型

| 账号类型 | 说明 | 典型场景 |
|----------|------|----------|
| BROKER | 券商账号 | 股票、场内ETF |
| FUND_PLATFORM | 基金平台 | 场外基金（天天基金、蛋卷基金等） |
| ALIPAY | 支付宝 | 基金、理财 |
| BANK | 银行账号 | 银行理财 |
| OTHER | 其他 | 雪球、东方财富自选股等 |

### 3.2 账号功能

| 功能 | 说明 |
|------|------|
| 添加账号 | 填写账号名称、类型 |
| 编辑账号 | 修改账号名称、类型、隐藏状态 |
| 删除账号 | 删除前需先删除关联的持仓 |
| 账号隐藏 | 设为隐藏后不在列表显示 |
| 账号排序 | 自定义排序顺序 |

### 3.3 持仓与账号关系

- 每条持仓记录关联一个账号
- 同一标的可在不同账号持有（如 A 股在东方财富，基金在支付宝）
- 持仓分析时可查看各账号的持仓明细
- 组合分析时支持按账号分别展示或汇总展示

## 五、信任与合规设计

### 5.1 AI 分析透明度

| 层级 | 呈现内容 |
|------|----------|
| 结论层 | 建仓/持有/观望建议 + 置信度 |
| 分析层 | 多维度评分（技术面/基本面/资金面等） |
| 依据层 | 关键数据点（PE/MA20/主力资金等） |
| 逻辑层 | AI 推理过程的自然语言解释 |
| 风险层 | 潜在风险提示 + 免责声明 |

### 5.2 置信度体系

| 置信度区间 | 信号强度 | 建议操作 |
|------------|----------|----------|
| 90-100% | 强烈 | 重点关注，可适当加大仓位 |
| 70-89% | 较强 | 建议关注，正常仓位 |
| 50-69% | 中性 | 仅供参考，需结合其他信息 |
| 30-49% | 较弱 | 谨慎操作，小仓位试探 |
| < 30% | 弱 | 建议观望 |

### 5.3 免责声明场景

| 场景 | 提示内容 |
|------|----------|
| 首次使用 | "AI 仅供参考，不构成投资建议。投资有风险，入市需谨慎。" |
| 每次分析 | "历史表现不代表未来收益。此分析基于当前数据，可能存在延迟或误差。" |
| 高风险操作 | "⚠️ 此操作风险较高，请确认您已了解相关风险" |
| 实盘信号 | "⚠️ 实盘信号仅供提醒，请确认已了解策略逻辑后再操作" |
| 数据异常 | "⚠️ 数据可能存在延迟或误差，请以交易所官方数据为准" |

## 六、风险与挑战

| 风险 | 应对措施 |
|------|----------|
| **数据延迟/准确性** | 标注数据来源，明确延迟时间 |
| **AI 建议失误** | 强调顾问型定位，明确免责条款 |
| **用户期望过高** | 教育用户，建立正确预期 |
| **合规风险** | 合规审查，明确不提供实盘交易 |
| **策略回测过拟合** | 提示历史不代表未来，多基准对比 |

## 七、与竞品差异化总结

| 维度 | 同花顺/东方财富 | 雪球 | **我们的方案** |
|------|-----------------|------|----------------|
| **AI 能力** | 无/基础选股条件 | 社区讨论 | **深度 AI 分析 + 透明推理链** |
| **个性化** | 标准服务 | 社区分享 | **基于用户偏好的定制建议** |
| **策略工具** | 简单条件单 | 无 | **可视化策略工作室 + 自定义脚本** |
| **持仓诊断** | 基础统计 | 帖子分享 | **AI 驱动的智能诊断 + 操作建议** |
| **回测系统** | 无 | 无 | **多基准对比回测 + 置信度统计** |
| **透明度** | 黑盒 | 社区验证 | **展示分析逻辑 + 置信度 + 风险提示** |
| **推送** | 基础行情 | 社区动态 | **AI 智能推荐 + 策略信号** |
