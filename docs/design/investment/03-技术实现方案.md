## 三、数据库设计

数据库详细设计请参见：[sql.md](sql.md)

### 设计要点

- **遵循规范**：遵循 `docs/specs/postgresql.md` 中的命名规范、表设计规范、索引规范
- **10 张核心表**：新增 `t_account` 投资账号表
- **账号关联**：`t_position` 和 `t_position_trade` 关联 `account_id`
- **账号功能**：支持账号类型、隐藏设置、排序
- **Flyway 迁移**：通过 Flyway 管理数据库迁移版本
- **触发器**：使用触发器自动更新 `updated_at` 字段

## 八、缓存策略

### 8.1 Redis 缓存设计

| 缓存 Key | 类型 | 过期时间 | 说明 |

### 8.2 缓存配置示例

```java
@Configuration
public class InvestmentCacheConfig {
    
    // 实时行情缓存（5分钟过期）
    @Bean
    public RedisCacheManager quoteCacheManager(RedisConnectionFactory connectionFactory) {
        return RedisCacheManager.builder(connectionFactory)
            .cacheDefaults(RedisCacheConfiguration.defaultCacheConfig()
                .entryTtl(Duration.ofMinutes(5))
                .serializeKeysWith(RedisSerializationContext.SerializationPair.fromSerializer(new StringRedisSerializer()))
                .serializeValuesWith(RedisSerializationContext.SerializationPair.fromSerializer(new Jackson2JsonRedisSerializer<>(QuoteData.class))))
            .build();
    }
    
    // AI 分析结果缓存（30分钟过期）
    @Bean
    public RedisCacheManager analysisCacheManager(RedisConnectionFactory connectionFactory) {
        return RedisCacheManager.builder(connectionFactory)
            .cacheDefaults(RedisCacheConfiguration.defaultCacheConfig()
                .entryTtl(Duration.ofMinutes(30)))
            .build();
    }
```

### 9.2 推送服务实现

```java
@Service
public class PushService {
    
    @Autowired
    private PushRecordRepository pushRecordRepository;
    
    @Autowired
    private UserSettingRepository userSettingRepository;
    
    @Autowired
    private MessageClient messageClient; // 消息推送客户端
    
    @Async
    public void sendBuildRecommend() {
        // 1. 获取所有开启推送的用户
        List<UserSetting> users = userSettingRepository.findByPushEnabledTrue();
        
        // 2. 生成推荐内容
        List<StockRecommendation> recommendations = generateRecommendations();
        
        // 3. 推送消息
        for (UserSetting user : users) {
            PushMessage message = buildPushMessage(user, recommendations);
            messageClient.send(user.getUserId(), message);
            
            // 4. 记录推送历史
            savePushHistory(user.getUserId(), PushType.BUILD_RECOMMEND, message);
        }
    }
    
    private PushMessage buildPushMessage(UserSetting user, List<StockRecommendation> recommendations) {
        // 14:45 推送内容模板
        return PushMessage.builder()
            .title("今日投资机会推荐")
            .content(buildRecommendContent(user, recommendations))
            .type(PushType.BUILD_RECOMMEND)
            .priority(PRIORITY_HIGH)
            .build();
    }
}
```

## 十二、功能扩展设计

### 12.1 基金/非基金持仓区分

系统支持三种持仓类型，每种类型的录入字段不同：

| 类型 | 录入字段 | 计算字段 | 示例 |
|------|----------|----------|------|
| **股票/STOCK** | 持仓份额(shares)、成本价(avg_cost) | 市值、收益率、盈亏 | 贵州茅台、宁德时代 |
| **ETF/ETF** | 持仓份额(shares)、成本价(avg_cost) | 市值、收益率、盈亏 | 沪深300ETF、创业板ETF |
| **基金/FUND** | 持仓金额(amount)、持仓收益(profit) | 净值、收益率 | 场外公募基金 |

**字段说明**：
- `shares` + `avg_cost` → 计算市值 = shares × current_price
- `amount` + `profit` → 计算净值 = amount + profit

### 12.2 加仓/减仓功能

用户可以通过手动录入的方式进行加仓和减仓操作：

**加仓流程**：
1. 用户选择持仓标的
2. 输入加仓金额（或份额）和价格
3. 系统自动计算新的平均成本
4. 生成交易记录

**减仓流程**：
1. 用户选择持仓标的
2. 输入减仓份额（或金额）
3. 系统计算剩余持仓和收益
4. 生成交易记录

**交易记录表（t_position_trade）**：
- 记录每次买入/卖出操作
- 便于用户查看历史操作
- 支持成本价追溯计算
